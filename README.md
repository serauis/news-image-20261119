One image that sums up the world's news of Thursday 19 November 2026, entered in make.fun's
[“Sum up 19 November's world news in one image”](https://make.fun/bounty/news-image-20261119)
bounty. A newspaper front page with 30 stories of the day — the first Trump–Xi–Putin
three-way summit in Shenzhen, the World Court's genocide ruling against Myanmar,
Anthropic's record $81bn IPO amid a Wall Street slide, GTA VI's worldwide launch,
Ukraine's third strike on the Crimean Bridge, COP31, Cyclone Akvan, and 21 more —
each attributed to its source (BBC, Reuters, AP, AFP, Al Jazeera, UN News, Euronews,
Dow Jones). The page is composed in code (`build_v3.py`, Pillow) from original
illustrations; `main.py` writes the finished 1024×1024 PNG to `/output/entry.png`,
byte-for-byte identical on every run, with no network access.

## Run it

```sh
python3 main.py
```
